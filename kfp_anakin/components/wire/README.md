# Wire

| Component | What it does |
|---|---|
| [`wire_build`](wire_build/README.md) | Ask Anakin to build a new Wire action for a site that isn't in the catalog. |
| [`wire_build_status`](wire_build_status/README.md) | Check a Wire build request started with wire_build. |
| [`wire_catalog`](wire_catalog/README.md) | One Wire site's actions: parameter schema, mode, auth mode, credit cost. |
| [`wire_catalogs`](wire_catalogs/README.md) | List every site in the Wire catalog with its action count. |
| [`wire_discover`](wire_discover/README.md) | Find Wire actions for a task described in plain language. |
| [`wire_identities`](wire_identities/README.md) | List your saved Wire identities (site accounts) and their credentials. |
| [`wire_login`](wire_login/README.md) | Sign in to a site that needs credentials and get a credential_id. |
| [`wire_read_action`](wire_read_action/README.md) | Run a Wire read action, which extracts data without changing anything on the site. |
| [`wire_write_action`](wire_write_action/README.md) | Run a Wire write action: submit a form, add to cart, post content, update settings. |
