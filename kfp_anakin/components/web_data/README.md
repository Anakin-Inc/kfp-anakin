# Web data

| Component | What it does |
|---|---|
| [`agentic_search`](agentic_search/README.md) | Multi-step research: search, scrape the cited pages, return a structured answer. |
| [`crawl_site`](crawl_site/README.md) | Fetch markdown for many pages of a site in one job. |
| [`map_site`](map_site/README.md) | Discover the URLs on a site (sitemap plus link traversal). |
| [`scrape_url`](scrape_url/README.md) | Scrape one URL to markdown, optionally extracting structured JSON with AI. |
| [`search`](search/README.md) | AI web search with citations. Synchronous. |
