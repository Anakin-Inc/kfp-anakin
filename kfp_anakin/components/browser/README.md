# Browser

| Component | What it does |
|---|---|
| [`browser_task`](browser_task/README.md) | Run a task described in plain language in a cloud browser driven by an AI agent. |
| [`session_delete`](session_delete/README.md) | Permanently delete a saved browser session and its encrypted login data. |
| [`session_list`](session_list/README.md) | List saved browser sessions (logged-in states you created in the Anakin dashboard). |
